# Bank System & Currency Exchange

A comprehensive console-based banking application built using C++ to demonstrate advanced Object-Oriented Programming (OOP) principles. This system simulates a real-world banking environment, featuring a custom file-based database for data persistence without relying on external SQL engines.

## Key Features

### Client Management
* **CRUD Operations:** Full Create, Read, Update, and Delete capabilities for client accounts.
* **Secure Storage:** Custom file handling system for storing client data efficiently.

### Transactions System
* **Deposits & Withdrawals:** Real-time balance validation and updates.
* **Money Transfer:** Secure transfers between accounts with automatic logging to a `TransferLog` file.

### Currency Exchange Module
* **Currency Management:** Update exchange rates and manage currency data.
* **Currency Calculator:** Converts amounts between any two currencies dynamically using USD as a reference.

### User Management & Security
* **Permissions System:** Role-based access control allowing admins to restrict feature access for specific users.
* **Security:** Encryption for user passwords and activity logging.

## Technical Highlights
* **Layered Architecture:** Separation of User Interface (Screens) from Business Logic.
* **OOP Principles:** Extensive use of Inheritance, Polymorphism, and Encapsulation.
* **Clean Code:** Structured for maintainability and scalability.
